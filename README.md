# Create: Big Cannons Multi Purpose Ballistic Calculator

Considering there is only one other ballistic calculator for this mod that I could find, I have decided to make one with enhanced features. The constants for solving the firing solutions are roughly the same, however, the algorithm used to obtain this solution is quite different. This calculator should provide supreme accuracy, as it actually simulates every single tick of the projectile's movements. As well as that, this calculator has [planned] compatibility for CBC: Modern Warfare, Valkyrien Skies integration, and Create: Aeronautics (With CC:VS and Create: Avionics as dependencies respectively) in the lua versions of the files. The [planned] Python version is an executable which runs with a GUI, including extra features to directly change physical constants, choose from a dropdown menu of different CBC: Modern Warfare projectiles, and ballistic trajectory graph generation.
